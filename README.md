🌱 SoyaCross – Soybean Disease Detection System

SoyaCross is a machine learning–powered soybean disease detection system designed to identify leaf diseases accurately and efficiently using images. The project focuses on early disease detection to help reduce crop losses and support smart, sustainable agriculture through mobile-based deployment.

📌 Problem Statement

Soybean crops are highly susceptible to diseases such as soybean rust and bacterial blight, which significantly affect yield and quality. Traditional disease detection relies on manual inspection, which is time-consuming, labor-intensive, and error-prone.
SoyaCross leverages Machine Learning and Computer Vision to provide a faster, scalable, and more reliable solution.

🚀 Key Features

📷 Image-based soybean leaf disease detection

🤖 CNN-based machine learning model

⚙️ System Workflow

Image Acquisition
Leaf images captured using smartphones or imaging devices.

Image Preprocessing
Resizing, normalization, noise reduction, and color enhancement.

Feature Extraction & Model Training

CNN-based model trained on soybean leaf images

Transfer learning using ResNet for improved accuracy

Model Optimization

Converted trained model to ONNX format for mobile deployment

Inference & Prediction

ONNX model loaded into the mobile application

Real-time disease prediction on new images

📊 Model & Architecture Highlights

ResNet Architecture with skip connections to prevent vanishing gradients

Transfer Learning using ImageNet pre-trained weights

ONNX Runtime for efficient and fast mobile inference

Focus on lightweight and optimized models for edge deployment

🧪 Challenges Faced & Learnings

Extensive backend and inference testing to isolate ML vs backend issues
